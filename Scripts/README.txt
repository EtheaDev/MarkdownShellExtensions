Scripts used by TEdgeMarkdownViewer (WebView2) to draw math formulas and mermaid
diagrams without an Internet connection: the viewer looks for this folder next
to the executable (or in its parent folder), otherwise it loads them from CDN.

- katex   : KaTeX 0.16.11 (https://katex.org) - MIT License (katex\LICENSE)
- mermaid : mermaid 11.17.2 (https://mermaid.js.org) - MIT License (mermaid\LICENSE)
